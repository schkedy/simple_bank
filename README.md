Simple Bank

Simple Bank — это учебный проект, демонстрирующий основы разработки банковского API с использованием Go, SQL и Docker. Проект включает в себя создание RESTful API для управления счетами, транзакциями и пользователями, а также использование тестирования и миграций базы данных.

🚀 Возможности

Создание и управление пользователями: регистрация, авторизация, обновление и удаление.

Управление счетами: создание, удаление и получение информации о счетах.

Транзакции: перевод средств между счетами.

Тестирование: покрытие кода юнит-тестами.

Миграции базы данных: автоматическое применение изменений схемы базы данных.

🛠 Технологии

Go — основной язык программирования.

PostgreSQL — система управления базами данных.

Docker — контейнеризация приложения.

sqlc — генерация SQL-кода из схемы базы данных.

Testify — библиотека для тестирования.
